# Airport Weather — Android APK

Приложение для просмотра погоды и METAR по ICAO-коду аэропорта.  
Сборка через **GitHub Actions + Capacitor** — Android Studio и SDK на компьютере не нужны.

## Возможности

- Поиск аэропорта по ICAO-коду (база 85 000+ аэропортов)
- Текущая погода (Open-Meteo)
- Сырой METAR + простая расшифровка
- Русский интерфейс
- Работает офлайн с локальным кэшем популярных российских аэропортов

## Быстрая сборка APK

1. Создайте новый репозиторий на GitHub (можно приватный).
2. Загрузите **все файлы** из этой папки в корень репозитория.
3. Откройте вкладку **Actions**.
4. Выберите workflow **Build Android APK** → **Run workflow**.
5. Дождитесь завершения (обычно 3–6 минут).
6. Внизу страницы run откройте **Artifacts** → скачайте `airport-weather-debug-apk`.
7. Распакуйте и установите `app-debug.apk` на Android-устройство.

> При первой установке Android может предупредить о «неизвестном источнике» — это нормально для debug-сборки.

## Локальная разработка (по желанию)

```bash
npm install
npx cap add android   # один раз
npx cap sync android
npx cap open android  # откроет Android Studio
```

## Используемые API

| Сервис              | Назначение                          |
|---------------------|-------------------------------------|
| FreeAirportDB       | Координаты и название аэропорта     |
| Open-Meteo          | Текущая погода                      |
| Rotate Pilot        | METAR                               |

## Примечания

- Debug-сборка подписана debug-ключом (подходит для тестирования).
- Для публикации в Google Play нужна release-сборка с вашим keystore.
- Интернет в приложении обязателен (данные берутся из внешних API).
